# Bread 'n' Butter — restaurant repo template

Every restaurant on Bread 'n' Butter is born from this repository: it carries the
restaurant's AI memory, the kitchen skills (invoice intake, recipe costing, menu
import, recipe entry), the re-cost job and the agent job. Owners never open it;
Bread 'n' Butter operates it for them.

The template's contents are being extracted from the pilot (Lyte-Works/bread-n-butter)
and arrive in a pull request. This first commit exists so the repository has a
`main` branch for the new-restaurant procedure to generate from.
